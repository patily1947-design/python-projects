# Python Practical Internship Projects 🚀

A collection of Python utility scripts developed during my Web Technologies & Cybersecurity internship at Unified Mentor.

---

## 📂 Projects Included

### 1. Laptop Battery Status Monitor (`battery.py`)
* **Description:** A script that monitors real-time laptop battery metrics using the `psutil` library.
* **Features:** 
  * Checks current battery percentage.
  * Checks if the power cable is plugged in.
  * Converts remaining seconds into a readable `Hours:Minutes:Seconds` format.
* **Libraries Used:** `psutil`

### 2. Python Calendar Generator (`calendar.py`)
* **Description:** An interactive utility script that generates and displays a formatted calendar for any given year and month.
* **Features:** 
  * Accepts dynamic user input for year and month.
  * Renders clean console-based grid output.
* **Libraries Used:** `calendar`

---

## 💻 How to Run Locally

1. Make sure you have Python installed on your system.
2. Install the required dependency for the battery script:
   ```bash
   pip install psutil
3. Run the scripts via your terminal or VS Code:
   ```bash
   python battery.py
   python calendar.py
   ```
